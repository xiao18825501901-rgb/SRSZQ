# INVICTUS_POLICY_COLLAPSE_RCA_REPORT

> 最新一轮实验报告：5K 政策坍塌的发现、根因、修复迭代与验证状态。
> 生成时间：2026-09-10（UTC 午后）；数据来源：官方 5000 局 run + 5K 评估链 + 两轮 scratch 验证训练（真实实测，非估算）。

**结论：POLICY COLLAPSE 确认（非风险，是事实）。**

## 2. 根因（代码级，三个叠加因素）

1. **根节点 Dirichlet 混用错误**（`mcts/nn_mcts.py`）：训练时根先验 = ε·Dirichlet + (1−ε)·**均匀分布**，而非 AlphaZero 的「(1−ε)·网络先验 + ε·Dirichlet」。后果：根节点选择与网络策略脱钩；而内部节点用网络自己的尖先验、无任何噪声 → PUCT 先验主导 → 访问完全集中 → 目标 one-hot → 网络先验更尖 → 正反馈坍塌。
2. **无策略熵正则**：loss = policy CE + value CE + L2，没有任何抵抗 one-hot 的项。
3. **稀疏访问 → one-hot 目标**：16 sims 对 ~150 合法步，访问分布天然稀疏，CE 目标近乎 one-hot，放大前两个因素。

（已排查并排除：value 视角/actor 映射正确；InferenceService 返回约定与直连路径一致；非法步 mask 正确。）

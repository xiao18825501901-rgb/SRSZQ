# 三人四子棋 · 水墨背景与手机布局更新

## 本次基线与范围

基于上一版 `SRSZQ_UI_Refresh_Complete.zip`，没有重新创建网站。
所有修改和新增的项目文件都位于 `frontend/`。后端、数据库、`shared/` 规则与 AI、npm 依赖和根目录启动脚本保持原始字节不变。

## 已改内容

### 全站背景

添加本地 SVG 山水背景：暖色宣纸、淡墨远山、湖岸、松竹和亭景。桌面与手机分别使用横向和竖向构图。
背景使用固定底层伪元素，禁止接收点击；不覆盖棋盘、图标和按钮。正文卡片与时间线使用高不透明度纸色底，规则长文增加清晰阅读底。
素材本地保存，不依赖第三方 CDN、图片站或字体下载；不会因为外部图片服务不可达而空白。

### 手机对局布局

900px 及以下采用同一棋盘与同一控件，仅调整 CSS 排列：

1. 对局标题与红 / 绿 / 白玩家状态。
2. 胜权时间线（棋盘上方）。
3. 水平居中的 13 / 17 路棋盘。
4. 落点 / 禁手与胜点开关（棋盘下方）。
5. 退出对局 + 在线时钟，或新游戏 / 悔棋 / 设置（棋盘下方）。
6. 棋局日志，以及展开后的复盘按钮 / 返回对局（棋盘下方）。

在线、好友、人机、离线和教学对局均应用这一布局。桌面继续保持棋盘左、状态与操作右。没有创建第二份棋盘或重复按钮。
